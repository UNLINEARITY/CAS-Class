# 国科大模拟选课系统 (CAS-Class)

一个面向国科大（UCAS）研究生的纯前端模拟选课工具。单文件、零依赖、零构建，双击即可使用，所有数据保留在本地。

> 本工具不与教务系统对接，仅用于选课前的课表规划与冲突预演，最终选课结果以教务系统为准。

## 功能特性

- **课程检索**：支持按课程名称、课程编码、教师姓名进行关键词搜索；提供院系、属性、层次、学分、考核方式五个维度的下拉筛选，可任意组合，并支持一键重置。
- **冲突选课**：添加与已选课程时间冲突的课程时，弹窗列出具体冲突时段，确认后可强行添加，便于在多个候选方案之间比较取舍。
- **备选课程**：候选课程可加入备选集合，与已选课程同图显示（半透明虚线块并带"备"字标识）、允许任意时间冲突且不计入冲突提示；支持搜索列表添加、课表右键互转与备选卡片中转正或移除，并随导出方案一并保存。
- **周课表**：支持第 1 至 22 教学周逐周查看；连续节次自动合并为整块；冲突课程在合并单元格内以半透明重叠并按车道错位显示，时间关系一目了然。
- **收藏偏好**：在课表中右键即可收藏候选课程，收藏课程以流动金色描边和淡金色光晕标识；收藏独立于选课持久化，移除课程不会丢失。
- **右键菜单**：在课表课程块上右键，即可复制课程代码、切换收藏状态或移除课程。
- **学分统计**：顶部实时显示已选门数、总学分（按公共选修课、公共必修课、学科核心课、专业核心课、专业课五类细分）以及本周课时段数。
- **信息完整**：每门课程均展示学分、课程属性、考核方式（闭卷笔试、课堂开卷、读书报告等）、授课教师、教室与上课周次。

## 使用方法

无需安装任何环境：

1. 下载 `index.html`；
2. 使用现代浏览器（Chrome、Edge、Firefox、Safari）直接打开；
3. 在左侧检索并添加课程，右侧实时查看课表。

已选课程与收藏偏好自动保存在浏览器的 `localStorage` 中，下次打开时自动恢复，全程不产生任何网络请求。

## 界面说明

| 区域 | 说明 |
|---|---|
| 顶部统计条 | 已选门数、总学分（含五类属性细分）、本周课时段数 |
| 课程检索 | 关键词与五维筛选组合查询，冲突课程以橙色按钮和"与 N 门冲突"标签预警 |
| 已选课程 | 以标签形式展示属性、学分、考核方式，收藏条目带金环与星标，长度不受限制 |
| 学期课表 | 13 节次 × 7 天网格，按教学周切换；收藏课程金色描边，冲突课程半透明重叠 |
| 备选课程 | 课表下方集中管理候选课程，显示学分小计；课表内以半透明虚线块呈现，支持转为已选或移除 |

课程配色按属性固定，共八种：公共选修课为青绿，公共必修课为橙色，学科核心课与专业核心课同为蓝色，专业课为红色，专业选修为绿色，实验课与实践课同为蓝紫色，研讨课为桃红色，其余属性以灰色显示。课表上方的图例仅列出当前选课涉及的类型，清空选课后自动隐藏。

## 数据说明

课程数据以 JSON 形式内嵌于 `index.html` 顶部的 `COURSES` 变量中（当前为 2026 年秋季学期，约 2000 门课程）。更换学期时只需替换该数据，无需改动任何逻辑代码。

单门课程的数据结构如下：

```js
{
  "id": 1,                          // 唯一标识
  "name": "抽象代数II",              // 课程名称
  "code": "180080070100M1004H",     // 课程编码
  "dept": "数学科学学院",            // 开课院系
  "attr": "学科核心课",              // 属性：公共选修课/公共必修课/学科核心课/专业核心课/专业课/研讨课/实验课/实践课等
  "level": "硕士课程",              // 层次：硕士课程/硕博通用课程/博士课程
  "exam": "闭卷笔试",               // 考核方式
  "hours": 60,                      // 学时
  "credits": 3.0,                   // 学分
  "cap": 35,                        // 容量
  "enrolled": 0,                    // 已选人数
  "sessions": [                     // 上课时段，可包含多个
    {
      "d": 2,                       // 星期，取值 1-7
      "s": 5,                       // 起始节次，取值 1-13
      "e": 6,                       // 结束节次，取值 1-13
      "w": [2,3,4,5,7,8,9],         // 上课的教学周列表
      "room": "教一楼311",           // 教室
      "teacher": "杨若涛"            // 授课教师
    }
  ]
}
```

## 技术要点

- 采用原生 HTML、CSS 与 JavaScript 实现，单文件分发，无外部依赖，无构建步骤。
- 冲突判定规则：同一天，且教学周存在交集，且节次区间存在交集。
- 课表渲染：对同一天内节次相交的课程做传递闭包聚类，整簇共享一个 `rowspan` 单元格，簇内课程块采用绝对定位与车道分配排布。
- 收藏描边：基于 `conic-gradient` 旋转动画与 `mask-composite` 实现金色流动描边；不支持 `@property` 的浏览器自动退化为静态金环。
- 兼容性：现代浏览器均可正常使用；浏览器禁用本地存储时功能不受影响，仅不记忆选课与收藏状态。
